# Не источник, а резерв

Код лендинга `calorybot.ru` живёт **в репозитории `calorybot`, в папке
`landing/`** — переехал туда 2026-09-18. Здесь лежит его замороженный снимок,
потому что на этом репозитории остались включёнными GitHub Pages: это тихий
резерв на случай долгого падения нашего VPS.

**Править здесь нечего.** Правка в этом снимке не попадёт на `calorybot.ru`
(apex-запись указывает на наш сервер) и разойдётся с настоящим лендингом — а
дальше, в момент переключения, отдаст клиенту оферту с другими ценами.

Зачем переехали: Impaya п. 5.4 запрещает принимающему платежи сайту жить на
бесплатном хостинге, а по п. 5.3 соответствие `my.calorybot.ru` зависит от того,
что основной сайт компании стоит на том же домене второго уровня. То есть эта
страница была несущей для проверки банка-эквайера — и стояла на бесплатном
хостинге.

Что важно знать про этот снимок:

- файл `CNAME` — не артефакт, а то, чем откат остаётся правкой DNS. Не удалять и
  не перезаписывать при синхронизации;
- синхронизация и переключение — по рецепту «Откат переноса лендинга» в
  `calorybot/DOCS/OPERATIONS.md`. Порядок обратный интуиции: сначала
  синхронизировать снимок, потом править DNS;
- расхождение цен между снимком и `landing/` ловит
  `calorybot/scripts/check_prices.py` — запускать до пуша сюда.
